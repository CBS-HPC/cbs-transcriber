    Library

    A library holds projects, transcripts and their history. Opening another library restarts the app; finish or cancel queued and running jobs first. The library you open is remembered for next time. Remove from list only hides a library. Delete permanently first shows exactly what would be deleted and kept; nothing is deleted until you confirm.

      Backups

      A complete backup copies all originals, saved results, history and available processing evidence. Finish or stop processing first. Keys and tokens are excluded.

          Research report

          Download a manifest and methods draft for each explicitly marked Working version in the project. Unassigned recordings are omitted. Metadata only is the default.

          Includes known processing history and explicit evidence gaps. Excludes recordings, discarded original text, notes and the full historical text collection. Hashes can still be linkable; review the report before sharing. This is a methods draft, not a journal-compliance certificate.

          Topics & sentiment (prototype)

          Manual evidence coding and imported suggestions. No automatic model, scoring or upload. Coding interprets a frozen text version; it does not change the transcript. Uncoded passages do not mean a topic is absent.

          Project topic codebook

          Define topics and coding rules. Saved versions retain stable topic IDs; retire topics instead of removing them.

          Import suggestion JSON
