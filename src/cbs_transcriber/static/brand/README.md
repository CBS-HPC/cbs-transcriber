# Official CBS brand assets

Downloaded unchanged on 20 October 2026 from the public
[CBS design guide](https://design.cbs.dk/en/cbslogo-fonts-colours-and-design/).

- `cbs-logo.svg`: https://design.cbs.dk/wp-content/uploads/CBSlogo_rgb_blue.svg
- `cbs-logo-vertical.svg`: https://design.cbs.dk/wp-content/uploads/CBSlogo_vertical_rgb_blue.svg
- Fonts: https://design.cbs.dk/wp-content/uploads/cbs-fonte__2023-01-03.zip
  - `CBS-New-Bold.ttf` is the package's `CBS NEW BOLD.ttf` (unchanged bytes).
  - `CBS-Sans-Regular.ttf` is `CBSSans-Regular.ttf` (unchanged bytes).
  - `CBS-Sans-Bold.ttf` is `CBSSans-Bold.ttf` (unchanged bytes).

The logo's geometry, proportions, and CBS blue (#4967AA) are preserved. CSS does
not recreate, crop, stretch, or recolour it. The primary logo identifies the app;
the official vertical variant is the favicon.

CBS New Bold is used for display headlines only. Readable web text uses CBS Sans,
CBS's named distribution of Inter. All assets are served locally for offline use.
