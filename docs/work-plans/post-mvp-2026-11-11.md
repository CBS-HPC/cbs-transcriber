## Decisions retained from earlier work

Longer term, expand the existing speech/model catalogue for CBS-relevant languages and
measured 1g MIG compatibility, quality, capabilities and licence/access evidence. Keep
candidates distinct from tested app/runtime/model combinations. This roadmap addition is
not permission to download weights, benchmark providers or broaden the current frontend.

First-launch credentials and direct OpenAI deactivation are explicit frontend requests.
Other layouts await colleague feedback. The Text-following prototype stays default-off.
PII-Tracer is a token classifier, not a chat-completions model; UCloud control keys and HF
tokens must not be sent as its inference bearer token. Historical synthetic hosting evidence
does not establish current uptime or Danish interview accuracy. Identifier/replacement/key
policy must be explicit; no automatic publication or overwrite of Working transcripts follows.

Native Transcriber language selection already follows each recording/project choice; this
morning's questions do not authorize another language redesign. Batch enhancement of saved
results, broad screen-reader acceptance and the other audited tasks retain their existing
scope. CBS Runtime live work, spelling, cloud backup transfers, automatic second-pass
alignment, held engines and the deferred Custom/UCloud vLLM UI remain outside this change.
