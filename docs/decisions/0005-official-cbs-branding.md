# Official CBS branding served locally

Accepted, 2026-10-20. Use unchanged CBS SVG logos and fonts from CBS's public
design guide, with CBS blue (#4967AA) as the primary interactive colour and
the official secondary palette for status and speaker distinctions. CBS New Bold
is restricted to display headlines; CBS Sans (Inter) carries readable web text.
Bundling the selected assets adds about 1.5 MB but keeps the local app independent
of external font or logo servers. Sources and font notices live beside the assets;
the layout retains logo proportions and uses its square motif without redrawing it.
