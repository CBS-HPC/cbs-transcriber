# Local Python web application

Accepted, 2026-10-20. Run FastAPI on loopback and serve a custom, build-free browser UI.
The user selected local-browser delivery and Python; native HTML media controls and small
JavaScript modules provide synchronized playback without a separate frontend toolchain.
The trade-off is a running local server and a small amount of browser code; desktop
installation and multi-user hosting need a separate deployment decision.
