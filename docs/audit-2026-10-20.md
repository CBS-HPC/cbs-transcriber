# Post-implementation audit — 20 October 2026

## Scope and method

Reviewed the feature/ucloud-transcriber application after the offline implementation
increments, including the independent enhancement runners and evaluation tooling.
Traced API → SQLite/files → worker/provider paths and frontend asynchronous state.
Used synthetic reproductions, temporary libraries, mocked UCloud/HTTP/SSH, real FFmpeg
on synthetic/licensed audio and Chromium workflows. This is a source/behavior audit,
not evidence of real inference quality or an independent penetration test.

## Reviewed boundaries

| Area | Checked behavior and practical limits |
| --- | --- |
| Persistence and storage | SQLite revision checks and active/result edits are atomic; originals/results remain recoverable. Project moves copy before switching, retain committed targets on finalization errors and reject links/active work. Central SQLite and keys stay in the library. |
| Jobs and concurrency | Shared claim lock/library lease; two media/two API workers and one enhancement worker. Part coordinator alone checkpoints sparse indexes and drains accepted requests. Restart requires explicit retry for interrupted work. Provider-wide UCloud capacity control remains deferred. |
| Provider policy and credentials | Standard/Protected defaults and explicit denial persistence; frozen provider identity and checks before protected transfers/retries. API/Activity omit raw params/chunks; keys stay scoped in credentials. SSH children receive no control-plane tokens. |
| Remote lifecycle | Native Transcriber, vLLM endpoints and SSH enhancement stay separate. Intent precedes allocation; unknown outcomes cannot auto-resubmit. Owned stop, shutdown/reconnect, stage validation and cleanup retry have mocked coverage. |
| Timing and editing | Word/free/restore transitions, Unicode offsets, untimed gaps, speaker splits and original restoration. Enhancement appends independent results from frozen reviewed text; uncertain words receive no proportional timings. |
| UI comparison/search/playback | Wording anchors/differences, read-only comparison, literal highlights in both panes, independent result selection, full playback and bounded Replay. Audio/video switching and byte-range playback remain covered. |
| Exports | Windows TSV/Mac timestamps/speakers/readable exports preserve first/last passages and Danish text; untimed native export fails clearly. Real desktop NVivo imports remain external acceptance. |
| Evaluation and architecture | Hashes stream from media; timing/speaker coverage and reported measurement scopes stay explicit. Heavy inference runtimes remain optional. Hosting-agent speech work is provider-owned (ADR 0020), not copied into the app. |

## Verification record

The first full audit run passed 221 tests, including twelve Chromium workflows.
The two additional history/zero-duration reproductions were then corrected; all 17
focused safety tests passed. The final suite passed **227 tests including twelve Chromium
workflows**, with Ruff, Python/JS formatting, JavaScript syntax and source/wheel checks passing.
Packaged recovery/provider/standalone-worker/frontend files and audit/spec/ADR sources were
inspected; no real environment files or databases were present. TODO.md records final evidence.
Ignored `test-results/audit-*.log` files retain local reproduction and verification logs.
Only synthetic/public fixtures were used; the running main server was not restarted.
